# Insurance Cost Analysis (R)

Exploratory analysis of a health insurance dataset with 1,300+ records to understand what drives medical insurance costs.

## Question
How do insurance charges vary across demographic and health factors, and which factors matter most?

## Tools
- **R**: data cleaning and analysis
- **ggplot2**: data visualization
- Correlation analysis

## Approach
1. Loaded and inspected the dataset, checking for missing or inconsistent values.
2. Explored how charges vary across demographics such as age, BMI, and smoking status.
3. Measured relationships between each factor and charges using correlation analysis.
4. Visualized the key relationships with ggplot2.

## Key Findings
- **Smoking status**, **age**, and **BMI** were the key drivers of insurance cost.
- Visualizations show how charges rise with these factors.

## Files
| File | Description |
| --- | --- |
| `insurance_analysis.R` | R script with the full analysis |
| `insurance.csv` | Dataset used in the analysis |

## How to Run
1. Install R and the `ggplot2` package: `install.packages("ggplot2")`
2. Open `insurance_analysis.R` and run it from the project folder.
